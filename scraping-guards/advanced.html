Scraping Guards — Tier 1 & Tier 2

Guards 26–41 are fully implemented. Guards 42–46 (orange) are simulated stubs — the real versions require network-layer infrastructure a Node server cannot reach. See docs/TIER3-COMMERCIAL.md for managed alternatives and pricing.

Base page with guards 0–25: index.html

26. CAPTCHA interstitial

Content behind /gated is served only after a challenge is solved. The operands render to a canvas, so solving needs OCR + arithmetic.

[not solved]

27. Proof-of-work challenge

Client must find a nonce where sha256(challenge:nonce) starts with 4 zero hex chars. Trivial once, costly at scraping volume.

[not attempted]

28. Glyph-substitution cipher font

The DOM below holds ciphertext; the remapped font renders the plaintext. Select and copy it — you get the gibberish, not what you see.

SYNT.TYLCUSBAG.q9p2

The plaintext appears nowhere in this document — not in the markup, not in a data attribute, not in JS. It exists only as the shape the font draws. Cipher: letters ROT13, digits +5, - ↔ .

29. AES-GCM encrypted payload

Server sends ciphertext + IV; the key is derived in-browser with PBKDF2 (100k iterations) and decrypted via crypto.subtle.

31. Per-request DOM randomization

Class and attribute names are regenerated on every response, so any scraper pinned to a selector breaks on the next fetch. Reload to see them change.

FLAG-DOMRAND-1f4c

This request used: .__RND1__, data-__RND2__, .__RND3__

32. Request header validation

Checks Sec-Fetch-*, Accept-Language, Sec-CH-UA Client Hints, header ordering, and known HTTP-library user agents.

Expect header-order-mismatch under Playwright/Selenium: the automation layer injects Accept-Language out of Chrome's natural position. Loading this page in a normal browser passes.

42. TLS fingerprint (JA3/JA4) — simulated

Real detection reads the ClientHello (cipher suites, extensions, curves and their order). Needs a TLS-terminating proxy. Force a verdict with X-Sim-JA3: python-requests|curl|Go-http-client|chrome.

[checking…]

43. HTTP/2 frame fingerprint — simulated

Real detection reads SETTINGS values/order, WINDOW_UPDATE, PRIORITY tree and pseudo-header order. Force with X-Sim-H2.

[checking…]

44. TCP/IP stack (OS) fingerprint — simulated

Real detection (p0f-style) needs raw packet capture: TTL, window size, MSS, option order. Force with X-Sim-OS.

[checking…]

45. IP reputation / ASN — simulated

Real detection needs a maintained feed (MaxMind, IPQualityScore, Tor exit list). Force with X-Sim-IP-Type: datacenter|vpn|tor|residential.

[checking…]

46. Connection-level limits — partly real

Concurrent sockets per IP are genuinely counted; TLS session resumption and H2 multiplexing are not observable here.
