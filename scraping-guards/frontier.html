Scraping Guards — Frontier (47–74)

Guards 47–74 extend the suite past the original 46. Blue = architectural, orange = simulated stub. Base pages: index.html (0–25), advanced.html (26–46).

47. Weighted risk scoring + proportional escalation

The architectural fix: signals contribute weight to one score, and the response scales with it — allow → challenge → tarpit → block — instead of 46 independent binary verdicts.

51. WebAssembly challenge

The decode routine lives in a hand-assembled 43-byte wasm module, not in readable JS. Ciphertext in the DOM; the module is the only key.

52. Labyrinth

/maze/* is an endless deterministic maze of plausible pages. robots.txt disallows it, so only a robots-ignoring crawler ever enters — which makes entry itself the signal.

[not entered]

53. Compression bomb

A small gzip response that expands to 2 MB, served only to clients already scored as blocked. Capped at 10 MB by design.

[not requested]

54. Content poisoning at scale

Guard 16 hid one static fake. This generates unlimited plausible, deterministic, entirely false records for clients that score as bots.

55. CSS sprite digits

The value below contains no numerals in the DOM — each digit is a background-position offset into one sprite image.

The markup carries only class="d d4" — no numeral appears anywhere in the DOM.

56. Pixel-only text

Server-rasterised with a built-in bitmap font — the string exists nowhere in the response, only as pixels.

Accessibility cost is real: this is invisible to screen readers.

59. Accounts, quota and device binding

The most effective real control: content behind an account with a per-key quota, bound to the device that minted it.

60. Mutual TLS

A second listener on port +1 requires a client certificate signed by our CA. Genuinely real — possession of a private key cannot be spoofed.

Browsers cannot demo this without an installed client cert; see tests/frontier.spec.js.

The signature covers method, path, timestamp, nonce and body hash, so a captured request cannot be modified or replayed.

/ai.txt, /llms.txt, robots.txt AI-crawler blocks, noai meta tags and TDM reservation headers.

71. HTTP/3 QUIC fingerprint — simulated

Real: QUIC transport parameters and Initial packet shape, via an HTTP/3 terminator.

72. Subtle data perturbation

Guard 54 fabricates whole records, which a scraper eventually notices — nothing reconciles. This returns the real catalogue with small deterministic drift: prices off by a few percent, stock flags sometimes flipped. Right shape, right magnitudes, consistent across re-fetches.

No marker field, unlike guard 54 — a marker is the one thing that would give it away. Provenance comes from the canary (41) instead.

[fetching…]

73. Per-character rendering

Every character is drawn into its own canvas, delivered in shuffled DOM order, with CSS order restoring the reading sequence. Even OCR over individual elements yields scrambled characters.

[loading…]

74. Tiered field-level access

Quota caps how much a scraper takes; this caps how much detail any account can see. Farming free accounts yields a strictly poorer dataset — premium fields are never in the response.
